# Programming.in.th Solutions

A C++ learning archive for problems from
[Programming.in.th](https://programming.in.th/) and related algorithm exercises.
It covers introductory syntax, arrays, matrices, simulation, search, and classic
competitive-programming techniques.

## Build a solution

```bash
g++ -std=c++17 -O2 -Wall -Wextra "Problem Name.cpp" -o solution
./solution
```

Each source file is a standalone exercise. Some files preserve earlier attempts
to show the learning process.
